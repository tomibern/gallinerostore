# Marca Gallinero Store

- `tokens.css`: colores y tipografías que pisan el tema neutro del núcleo.
- `public/`: se sirve en `/brand/` (lo copia `scripts/sync-brand.mjs`).
  - `logo.webp`: logo del dueño (escudo circular), 384 px. Falta el original en vector o en alta calidad (pregunta abierta en `docs/discovery.md`).
  - `fonts/oswald-latin.woff2`: Oswald de Google Fonts, licencia SIL Open Font License 1.1, subconjunto latino, pesos 500 a 700.
